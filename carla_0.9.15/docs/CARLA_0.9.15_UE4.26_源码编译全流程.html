14 / 排错索引

故障速查表

按错误关键词定位，不要因为依赖下载失败而把 UE/CARLA 全量删除重建。

GitHub 提示 Password authentication is not supported＋

原因：GitHub HTTPS 不接受账户密码；可能还缺 EpicGames 仓库权限。

处理：先完成 Epic ↔ GitHub 关联并接受邀请；gh auth login；git ls-remote 检查可访问性。

GLX BadValue / UE4Editor 崩溃＋

原因：本次同时存在 NVIDIA 内核/用户态不一致。

处理：nvidia-smi、/proc/driver/nvidia/version、modinfo；先重启，再检查 GLX/Vulkan 与 ToDesk 会话。

Failed to initialize NVML＋

原因：已加载内核模块 580.173.02，磁盘模块 580.178.04。

处理：安全保存工作后 sudo reboot；不要先 purge 全部 NVIDIA。

Boost gzip: stdin: not in gzip format＋

原因：旧 JFrog 跳到 HTML 页面，却保存为 .tar.gz。

处理：官方 Archives + 本地文件优先；用 file 与 gzip -t 验证。

B2: fatal error: 'thread' file not found＋

原因：UE 自带 Clang 10 bootstrap 时找不到 C++ 标准库头。

处理：仅将 bootstrap.sh --with-toolset=gcc，保留后面 Boost 库 clang-10.0。

libpng 404 Not Found＋

原因：旧版本已移动到 SourceForge older-releases。

处理：修复 LIBPNG_REPO 版本路径。

libpng SSL unexpected eof＋

原因：本地 VPN/代理到 SourceForge 镜像的 HTTPS 连接中断。

处理：本次换 VPN 节点后成功；也可下载后离线放入 Build。

tar: libpng-1.6.37.tar.xz: No such file＋

原因：URL 以 /download 结尾，wget 实际写成 download。

处理：wget -O libpng-1.6.37.tar.xz；或者验证 download 后重命名。

python: 未找到命令 / error 127＋

原因：Ubuntu 22.04 只有 python3，旧 CARLA 脚本调用 python。

处理：sudo apt install python-is-python3 或激活带 python 的合适 venv。

downloadplugins 警告：覆盖配方＋

原因：本次多次出现，构建仍继续。

处理：将其与真正导致退出的 make: *** / error 分开分析。

LogExit + cannot parse georeference＋

原因：只看到引擎退出与坐标参考警告。

处理：不能推断地图成功；需 Play 后用 Python API 读取地图并检查 GNSS 地理参考。
