1. 迁移步骤（另一台机器）

  1. 确认目标仓是 Autoware 1.7.1 + Humble，工作区根目录有 src/。
  2. 拷贝本目录三个文件到目标仓（建议放到 phase_trim/）： autoware_lite_trim_playbook.html、 lite_trim_ignore_packages.txt、 apply_lite_trim.py。
  3. 在目标仓根目录先 dry-run： 
    python3 phase_trim/apply_lite_trim.py --src src --list phase_trim/lite_trim_ignore_packages.txt --dry-run
  4. 确认 HARD_KEEP 没有被点名后，去掉 --dry-run 真正写入 IGNORE 并剥离 depend。
  5. 按下面「launch / preset」和「源码补丁」改文件（脚本不会自动改 C++）。
  6. colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
  7. 缺包编译失败时：对报错包的 package.xml 再删一行对 IGNORE 包的 depend，或按 CMake QUIET 补丁跳过测试。

2. 裁剪机制（必须一致）

做法效果可否回滚
在包目录放空文件 COLCON_IGNOREcolcon list/build 跳过该包删掉该文件即可
从仍编译的 package.xml 去掉 depend/exec_depend/test_depend避免 colcon 因缺失依赖失败对照 git 恢复
preset / launch 把模块开关设 false运行时不加载已裁插件改回 true
不要 rm 源码目录—本手册不走 DROP

车遇到障碍不再主动停/绕（N1）。横向默认 pure_pursuit。OSQP 保留。
